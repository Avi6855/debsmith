One manifest in.
A reproducible .deb out.

Builds the .deb, runs 30 Debian Policy checks, generates 3.0 (quilt) sources, signs an APT repository and proves the rebuild is byte-identical.

Deterministic .deb writer

zstd / gzip / xz, fixed root:root, zeroed mtimes, SOURCE_DATE_EPOCH timestamps.

30 Debian Policy checks

Names, modes, checksums, conffiles, scripts, archive safety. Text, JSON or SARIF 2.1.0.

Signed APT repository

pool/ layout, Packages, Release, clearsigned InRelease, Release.gpg.

3.0 (quilt) sources

.orig.tar.gz, .debian.tar.xz and a checksummed .dsc. dpkg-source ready.
